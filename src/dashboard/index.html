    What this dashboard shows

    We trained models to predict the Air Quality Index at 107 monitoring stations across eight Indian cities. Everything in Explore comes from test periods the models were not fitted on, so you can see how they would have done. None of it is today's air quality. For current readings, use the CPCB portal.

    AQI bands

    The Central Pollution Control Board's bands, used for every colour on this page.

    Words used here

    Forecast / next-day
    Uses only what was known before the target day. It could have been issued in advance.
    Estimate / same-day
    Uses satellite and weather data from the target day itself, so it can only be produced afterwards. It is not a forecast.
    Measured
    The station's AQI from CPCB exports. Each date's value is the 24-hour reading at the end of that UTC day, which is 05:00 IST the next morning.
    Yesterday's reading
    The simplest possible forecast: tomorrow equals today. A useful model has to beat it.
    Typical miss (MAE)
    The average distance between the model and the measurement, in AQI points.
    RMSE
    Like the typical miss, but large misses count more. This is the main score in the project report.
    90% range
    A band meant to contain the measurement on about 90% of days, set using calibration months before the test. It is available for single stations only.
    Bias
    The average signed miss. Negative means the model tends to read too low.
    City average
    The plain mean of whichever stations reported that day. It is not an official city AQI, and the set of stations can change from day to day.
    Backtest / held-out
    Scoring a frozen model on past data it wasn't fitted on. It is not the same as running live.
